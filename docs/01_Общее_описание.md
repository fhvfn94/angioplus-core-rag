# Общее описание проекта

## Название проекта AngioPlus Core AI Support Assistant

---

# Цель проекта
Разработка AI-ассистента для технической поддержки медицинского программного обеспечения AngioPlus Core.

Система предназначена для:
- помощи инженерам L1/L2 поддержки;
- быстрого поиска информации в документации;
- сокращения времени обработки запросов;
- снижения количества ошибок при консультациях.

---

# Основная идея
Система использует подход RAG (Retrieval-Augmented Generation):
1. Находит релевантную информацию в документации;
2. Передает найденный контекст языковой модели;
3. Генерирует ответ строго на основе найденных данных.

---

# Источники данных
В MVP используются:
- IFU (руководство пользователя);
- training-материалы;
- коммерческие материалы;
- документы L1/L2 поддержки.

---

# Основные возможности MVP
## Реализовано
- Индексация PDF и DOCX;
- Семантический поиск;
- Генерация ответов через LLM;
- Указание источников ответа;
- REST API;
- Telegram-бот.

---

# Основные ограничения MVP
## Не реализовано
- Safety layer;
- Валидация медицинских ответов;
- Confidence scoring;
- Автоматическая эскалация L3;
- Авторизация пользователей;
- Аудит действий.

---

# Статус проекта
Текущий статус:
MVP / Prototype
Проект предназначен для:
- демонстрации концепции;
- пилотного тестирования;
- оценки качества retrieval и AI-ответов.
