# API

# POST /ask

## Назначение
Получение AI-ответа на основе документации.

## Авторизация
Требуется заголовок `X-API-Key` со значением `RAG_API_KEY`.

- `401` — ключ отсутствует или неверный;
- `503` — `RAG_API_KEY` не задан на сервере.

## Ограничения запроса
- `question`: 1–2000 символов;
- `top_k`: 1–20 (по умолчанию 5).

`GET /health` доступен без авторизации.
