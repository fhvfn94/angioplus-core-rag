# Ограничения MVP

# Основные ограничения
## Safety
Отсутствует:
- медицинская валидация;
- проверка корректности ответа;
- hallucination detection.

---

# Security
Не реализовано:
- authentication;
- authorization;
- audit logging.

---

# AI Limitations
Возможны:
- retrieval errors;
- incomplete answers;
- ambiguity.

---

# Production Usage
Текущий MVP НЕ предназначен для:
- production;
- работы с PHI;
- клинических решений.
